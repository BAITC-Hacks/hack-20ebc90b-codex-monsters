## Как разрешены противоречия

Главный контекст: закупщик много раз в день проверяет товары и получает утверждённый CSV. Существующие страницы и серверные правила сохраняются. Приоритет имеют пользовательская задача и ограничения роли C, затем подходящие рекомендации навыков.

- `minimalist-ui` одновременно запрещает градиенты и предлагает их в декоративных разделах. Для нашего экрана выбран строгий вариант без градиентов.
- `minimalist-ui` предлагает плоские рамки, а `high-end-visual-design` их запрещает и требует глубину. Для рабочего инструмента выбраны тонкие разделители без декоративных теней.
- `emil-design-eng` рекомендует убрать движение из частых действий. Пружины и появления строк не нужны в таблице закупок; нажатие подтверждается мгновенным состоянием кнопки.
- Нативные элементы Streamlit сохраняют свою семантику, фокус и работу с клавиатуры. Не добавлены React, шрифтовые загрузки или UI-библиотеки.

## Применённые изменения

| До | После | Польза |
|---|---|---|
| Разделы выглядели как набор параметров с радиокружками | Полоса разделов с фоном и подчёркиванием выбранного | Текущее местоположение видно без цветового акцента |
| Ярко-красная штатная основная кнопка | Контрастная монохромная кнопка в обеих темах | Главное действие выделено без конкуренции с предупреждениями |
| Каждый блок подробностей заключён в рамку | Один тонкий разделитель под раскрывающимся блоком | Меньше визуальных контейнеров вокруг второстепенной информации |
| Малозаметные подписи | Контрастный вторичный текст | Дата, версия, ограничения и происхождение данных легче читать |
| Ожидание HTTP-операции без пояснения рядом с результатом | «Сохраняем количество…», «Утверждаем проверенную версию…», «Готовим утверждённый CSV…» и подписи запуска расчётов | Пользователь понимает, какое действие выполняется |
| Двойная точка после «шт.» | Одна точка | Аккуратные подписи товара |

Стили находятся в `apps/buyer_ui/styles.css`. Палитра использует CSS `light-dark()` и установленный Streamlit `color-scheme`, поэтому переключается сразу вместе со штатным меню темы. Основные кнопки и навигация имеют высоту не меньше 44 px; видимый фокус сохраняется. Для `prefers-reduced-motion` переходы навигации и кнопок отключены. Цвет ошибок и предупреждений остаётся семантическим.
