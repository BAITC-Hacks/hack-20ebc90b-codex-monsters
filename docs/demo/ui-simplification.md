# Упрощение интерфейса закупщика

Дата: 23 сентября 2026. Причина: основной экран показывал технические операции, полный расчёт, редактирование и экспорт одновременно. Закупщик не понимал, с чего начать.

## Источники и выбранный подход

- [Impeccable](https://github.com/pbakaus/impeccable), навыки `distill`, `clarify`, режим `operate`: один основной результат, последовательное раскрытие подробностей, названия действий на языке пользователя.
- [Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design): ясная визуальная иерархия, сдержанность в оформлении и тексте.

Навыки установлены локально, их исходники не добавлены в продукт. Автоматический загрузчик контекста Impeccable не прошёл проверку загрузки; использованы прочитанные инструкции и контекст репозитория, без запуска непроверенного бинарного файла.

Продуктовый контекст: закупщик проверяет рассчитанное сервером предложение и получает утверждённый CSV. Это рабочий инструмент, поэтому сохранены стандартные элементы Streamlit и текущая светлая/тёмная тема. Новых зависимостей нет. Оформление: один системный шрифт, спокойная шкала заголовков, цвет только для состояния и основного действия, ширина рабочей области до 1120 px. Главный акцент — таблица товаров и следующее действие с заказом.

## Новый путь

```text
Заказы: поставщик → товары → утвердить и подготовить CSV → скачать CSV
                         ↘ проверить или изменить товар
Что, если…: параметры → сравнить с исходным расчётом
Данные: подготовить данные → рассчитать заказ → открыть заказы
```

| Было | Стало |
|---|---|
| Открытая боковая панель подключения | Настройки по отдельной кнопке |
| Все три вкладки исполняются при каждом действии | Загружается только выбранный раздел |
| ID предложения и строки в основном списке | Название товара, артикул, количество с единицей, срочность, сумма |
| Фильтр по техническому ID на первом плане | Поиск по товару и артикулу; ID поставщика в «Ещё» |
| Неактивные кнопки страниц при двух поставщиках | Пагинация только при наличии страниц |
| Формулы и редактор раскрыты сразу | «Проверить или изменить товар»; объяснение по запросу |
| Длинные дроби в расчёте | До трёх знаков для чтения; точные серверные значения доступны отдельно |
| Утвердить → подготовить → скачать | Утвердить и подготовить → скачать |
| Создание snapshot, job/run IDs, источники и проекты на одном уровне | Текущие данные и расчёт на первом плане, импорт/параметры/проекты раскрываются по необходимости |

## Сохранённые гарантии

- UI не пересчитывает бизнес-формулы. Количества в запросах и байты CSV не округляются интерфейсом.
- Утверждается точная просмотренная версия. Фильтр товаров не меняет состав утверждаемого заказа.
- Несохранённое количество нужно сохранить или отменить перед утверждением/выгрузкой.
- Утверждение и экспорт остаются разными серверными операциями. При сбое экспорта повторяется только экспорт с прежним ключом запроса; утверждение не теряется.
- Изменение версии между утверждением и экспортом останавливает выгрузку. Правка утверждённого заказа требует нового утверждения.
- Синтетические данные, временная модель и исключённые товары обозначены. Блокирующие причины не спрятаны.
- Сценарий не меняет исходный заказ. Источники предварительно регистрируются на сервере, загрузки файлов и отправки поставщику нет.

Это реализация упрощённого пути, а не измеренное исследование удобства. Следующая пользовательская проверка: дать закупщику без инструкции найти товар, объяснить количество, изменить его и скачать заказ; наблюдать места остановки.

## Польза и критерии хакатона

Изменение усиливает «Ценность решения», «Результат и качество», «Презентация и демо»: основной путь виден сразу, редкие действия не конкурируют с заказом, получение CSV после проверки сокращено с трёх нажатий до двух. Доказательства — работающий интерфейс, сквозной HTTP-тест и ручной проход в браузере. Скорость работы закупщика и рост удобства численно не измерялись. Инновационность расчёта не менялась; дальнейшее масштабирование и ERP остаются за рамками UI-изменения.

Сервер подтвердил файл, UI показал «Скачать CSV». Исходный исторический run и его синтетические данные не изменялись. На узком экране таблица прокручивается по горизонтали.
